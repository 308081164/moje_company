## 字段

每条记录是一件建模。字段按表中顺序：

1. 编号
2. 建模图像
3. file
4. 建模师
5. day
6. 主体结构复杂度
7. 是否含纹理
8. 简单（直线线条）小组件
9. 一般复杂（少量规则曲线/复用）小组件
10. 复杂（较多不规则曲线）小组件
11. 高度复杂（高精度、多细节）小组件
12. 简单（常规构型）镶嵌结构
13. 特殊构型镶嵌结构
14. 线性排石（规律直线/曲线）
15. 不规则曲线/曲面排石
16. 折算系数

后 8 个数量字段记件数。折算系数是公式字段，类型为 Formula，显示格式 Default。

## 选项

主体结构复杂度：

- 无主体
- 普通构型（素圈）
- 异形（单圈形状微调）
- 异形（存在镂空、形状缠绕）
- 异形（戒圈完全重构）

是否含纹理：

- 不含纹理
- 含纹理
- 多种纹理

## 折算系数公式

字段「折算系数」的现用公式是：

```text
10
+ SWITCH([主体结构复杂度],
    "无主体", 0,
    "普通构型（素圈）", 3,
    "异形（单圈形状微调）", 15,
    "异形（存在镂空、形状缠绕）", 30,
    "异形（戒圈完全重构）", 45,
    0)
+ SWITCH([是否含纹理],
    "不含纹理", 0,
    "含纹理", 10,
    "多种纹理", 20,
    0)
+ [简单（直线线条）小组件] * 3
+ [一般复杂（少量规则曲线/复用）小组件] * 15
+ [复杂（较多不规则曲线）小组件] * 30
+ [简单（常规构型）镶嵌结构] * 5
+ [特殊构型镶嵌结构] * 10
+ [线性排石（规律直线/曲线）] * 15
```

每件先给 10 分底分，再按主体、纹理和各类件数加分。未匹配到的选项按 0 分。

下面两个字段已经建在表里，但没有写进这条公式，所以现在填了数量也不会增加折算系数：

- 高度复杂（高精度、多细节）小组件
- 不规则曲线/曲面排石

## 迁到订单系统时怎么取数

订单走完设计、建模之后，下面这些可以直接从单件上带出来，管理员不用再填：

| 飞书列 | 系统里对应的数据 |
| --- | --- |
| 编号 | 订单号 + 单件名 |
| 建模图像 | 该件的建模效果图 |
| file | 该件的建模源文件 |
| 建模师 | 订单上指派的建模师 |
| day | 该件建模信息的最后更新时间 |
| 对照用的设计图、珠宝类型、工艺、宝石、克重、建模备注 | 设计信息和建模信息里已经有，只帮助判断，不直接变成分数 |

这些是评审判断，订单流程里没有同等字段，必须由管理员看图后填写：

- 主体结构复杂度
- 是否含纹理
- 各类小组件、镶嵌结构、排石的件数

折算系数由公式自动算出，不手填。高度复杂小组件和不规则曲面排石可以先记下，当前公式不加分。

设计核算还没有对应的计件规则，页面先留空。订单里已经有设计师、设计图和客户确认时间，以后定了规则可以直接带出。
