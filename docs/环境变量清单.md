# 环境变量与密钥配置清单

本文档列出本仓库各组件依赖的**敏感配置**及常用环境变量。所有真实口令、AccessKey、JWT 密钥等**仅**通过本机 `.env`、服务器环境变量或 **GitHub Actions / 部署平台 Secrets** 注入，**勿**再写入 `application.yml`、Compose 或 Markdown 文档。

---

## 一、后端（Spring Boot，`backend/`）

| 变量名 | 说明 | 本地开发 | 生产 / Docker |
|--------|------|----------|----------------|
| `DB_HOST` | MySQL 主机 | 默认 `localhost` | 常为 `mysql` |
| `DB_PORT` | 端口 | 默认 `3306` | 默认 `3306` |
| `DB_NAME` | 库名 | 默认 `moje_database` | 同左 |
| `DB_USER` | 用户 | 默认 `root` | 按环境 |
| `DB_PASSWORD` | 数据库密码 | **必填** | **必填** |
| `JWT_SECRET` | JWT HMAC 密钥 | **必填** | **必填**（建议 ≥32 字符随机串） |
| `DEFAULT_ADMIN_PASSWORD` | 覆盖 Flyway 种子管理员密码 | **首次登录前必填** | **必填**（与 GitHub Secret 同名） |
| `DEFAULT_ADMIN_USERNAME` | 种子管理员用户名 | 默认 `kuangjun` | 可选覆盖 |
| `OSS_ACCESS_KEY_ID` | 阿里云 OSS AccessKey ID | 使用 OSS 时必填 | 同左 |
| `OSS_ACCESS_KEY_SECRET` | OSS AccessKey Secret | 使用 OSS 时必填 | 同左 |
| `OSS_BUCKET_NAME` | OSS Bucket 名称 | 使用 OSS 时必填 | 同左 |
| `ALIYUN_OSS_ENDPOINT` | OSS Endpoint（不含 `https://`） | 可选，默认 `oss-cn-guangzhou.aliyuncs.com` | 可按地域覆盖 |
| `JEWELRY_PUBLIC_BASE_URL` | 管理端/API 对外基址（无路径） | 按本机端口 | 公网 `https://...` |
| `B2B_PUBLIC_BASE_URL` | B2B 站点基址（与上二选一逻辑见 `application.yml`） | 可选 | 按部署 |
| `B2B_ACCESS_URL_PREFIX` | B2B 订单链接完整前缀 | 可选 | 可选 |
| `JEWELRY_CUSTOMER_ORDER_FRONTEND_URL` | 客户进度页前端基址 | 默认 `http://localhost:5173` | 公网 SPA 地址 |

**Flyway Maven 插件**（`mvn -f backend/pom.xml flyway:migrate` 等）：在 shell 中设置 `export DB_PASSWORD=...`，密码从环境变量读取，**不再**写在 `pom.xml` 中。

## 二、根目录 Docker Compose（`docker-compose.dev.yml` / `docker-compose.mysql.yml`）

启动前在仓库根目录准备 `.env`（可复制 `.env.example`）：

| 变量名 | 说明 |
|--------|------|
| `DB_PASSWORD` | MySQL root 与后端 `DB_PASSWORD` 共用 |
| `JWT_SECRET` | 后端 JWT |
| `DEFAULT_ADMIN_PASSWORD` | 种子管理员密码 |
| `DEFAULT_ADMIN_USERNAME` | 可选 |
| `OSS_ACCESS_KEY_ID` / `OSS_ACCESS_KEY_SECRET` / `OSS_BUCKET_NAME` | 可选；不配则 OSS 关闭 |
| `ALIYUN_OSS_ENDPOINT` | 可选 |
| `JEWELRY_PUBLIC_BASE_URL` | 可选，默认 `http://localhost:8851` |

示例：

```bash
cp .env.example .env
# 编辑 .env 填入真实值后：
docker compose --env-file .env -f docker-compose.dev.yml up -d
```

## 三、GitHub Actions：部署到服务器（`.github/workflows/deploy.yml`）

除已有的 `SSH_HOST`、`SSH_USERNAME`、`SSH_PASSWORD` 或 `SSH_PRIVATE_KEY` 等外，请补充：

| Secret 名称 | 说明 |
|-------------|------|
| `DB_PASSWORD` | 生产 MySQL root / 应用库密码 |
| `JWT_SECRET` | 生产 JWT 密钥 |
| `DEFAULT_ADMIN_PASSWORD` | 生产环境种子管理员登录密码 |
| `DEFAULT_ADMIN_USERNAME` | 可选；不设置则默认 `kuangjun` |
| `OSS_ACCESS_KEY_ID` | 阿里云 OSS |
| `OSS_ACCESS_KEY_SECRET` | 阿里云 OSS |
| `OSS_BUCKET_NAME` | OSS Bucket 名称（原 compose 中写死的 bucket 已改为由此注入） |
| `ALIYUN_OSS_ENDPOINT` | 可选；不设置则默认广州地域 endpoint |

## 五、已轮换的泄露项（务必在控制台操作）

若仓库曾公开且阿里云已告警：

1. 在**阿里云 RAM** 中**禁用并删除**已暴露的 AccessKey，**新建**一对并只写入 Secrets / `.env`。  
2. 修改曾出现在文档中的 **MySQL / SSH** 口令（若与真实环境相同）。  
3. 更换 **`JWT_SECRET`** 后，所有已签发 Token 失效，用户需重新登录。

## 七、Electron 自动更新（`frontend/package.json` → `build.publish`）

`publish[0].url` 已改为占位地址 `https://example.com/desktop-updates/win`。启用自动更新前，请改为你在 OSS（或静态站点）上**实际对外可访问**的更新目录基址，并勿把含 AccessKey 的私有 URL 写入仓库。
