# 生产订单信息由谁填写

对照线下《MOJE生产订单》。记录于 2026-10-24。

## 客户填写

支付定金时选择金属材质。足金、足银不能镶嵌宝石，问卷里也不出现镶石选项。

定金支付后，AI 客服在订单群聊发送问卷链接 `order-brief.html?orderId=`。客户按每一件填写：

- 品类：戒指、项链、胸针、耳钉/耳饰、手镯、锁骨链、发饰、小挂件、其他
- 戒指填圈号和单位；项链选择是否配链及样式；手镯填圈口；锁骨链选样式；发饰选种类
- 是否电镀和颜色
- 是否镶石：自选品类和颜色，或让设计师决定
- 是否珐琅
- 成品预算

设计师会参考这些选择并尽可能采纳，但不保证每一项都原样实现。更高预算可以支持更复杂、更精细、更考究的设计与工艺。

设计全部通过客户确认后，订单聊天弹出小问卷，由客户选择：

- 是否买断设计
- 是否需要版权证书
- 是否保密、不对外宣传

## 设计师填写

按每一件填写：

- 石料：种类、形状、尺寸、数量、重量、价格、备注。客户问卷只提供偏好
- 电镀颜色以客户问卷为准，设计师可按生产需要调整
- 表面工艺：拉丝、喷砂、钉砂，以及其他工艺。珐琅是否需要由客户选择
- 刻字（字印）
- 设计图

## 建模师

- 可以修改每一件的石料
- 上传的效果图自动作为生产订单右侧的建模预览图

## 仍由设计师可改

圈号、链子和圈口会写入订单尺寸，设计师可以按生产需要修改。其他工艺不在客户问卷里。
