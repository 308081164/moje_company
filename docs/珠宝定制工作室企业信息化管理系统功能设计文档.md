# 珠宝定制工作室企业信息化管理系统功能设计文档

## 1. 项目概述

### 1.1 项目背景
随着珠宝定制业务的快速发展，传统手工管理方式已无法满足企业高效运营需求。本系统旨在为珠宝定制工作室提供一套完整的企业信息化管理解决方案，实现订单全流程数字化管理，提升工作效率，降低沟通成本。

### 1.2 系统目标
- 实现订单从接洽到生产的全流程数字化管理
- 建立多角色协同工作平台
- 提供数据统计与分析功能
- 实现业务流程标准化和自动化

## 2. 系统角色定义

### 2.1 角色列表
| 角色 | 人数 | 主要职责 |
|------|------|----------|
| 管理员 | 1人 | 系统配置、用户管理、数据统计、权限控制 |
| 售前客服 | 若干 | 客户接洽、订单信息录入、定金收取 |
| 售中客服 | 若干 | 订单跟进、设计师/建模师分配、报价管理 |
| 设计师 | 若干 | 设计图制作、工艺信息录入、石料信息管理 |
| 建模师 | 若干 | 3D建模、克重计算、建模文件管理 |
| 跟单员 | 若干 | 工艺评审、质量把控、生产跟进 |

### 2.2 权限隔离原则
- 所有角色在系统内能够看到的内容独立，无法看到其他人的内容
- 基于角色的数据访问控制
- 操作权限按业务流程阶段划分

## 3. 核心业务流程

### 3.1 订单创建流程
```
售前客服接洽客户 → 录入订单基本信息 → 收取定金 → 订单进入"待设计师设计"状态
```

### 3.2 设计阶段流程
```
售中客服对接 → 填写字印/材质/手寸信息 → 分配设计师 → 设计师上传设计图 → 客户确认 → 进入建模阶段
```

### 3.3 建模阶段流程
```
售中客服分配建模师 → 建模师上传建模文件 → 客户确认 → 进入工艺评审阶段
```

### 3.4 报价与生产流程
```
跟单员工艺评审 → 售中客服完善报价 → 系统自动计算材质单价 → 标记为"待生产" → 生产完成
```

## 4. 功能模块详细设计

### 4.1 用户与权限管理模块

- 多角色统一登录入口
- 基于角色的界面定制
- 会话管理与安全控制

#### 4.1.2 角色管理

- 操作权限：按业务流程阶段控制
- 管理员拥有最高权限

### 4.2 订单管理模块

#### 4.2.1 订单创建（售前客服）
**必填字段：**
- 订单编号（系统自动生成+手动可调）
- 来源：抖音、B站、小红书、淘宝、闲鱼、达人推荐
  - 达人推荐需输入达人昵称
- 定金金额
- 基础需求描述
- 下单时间
- 款式信息
- 材质信息（从管理员配置的常见材质中选择）
- 客户联系方式

**功能特点：**
- 订单来源统计分析
- 定金记录与跟踪
- 客户信息管理

#### 4.2.2 订单对接（售中客服）
**待设计师设计栏目：**
- 查看所有待设计订单
- 点击"去对接"进入对接界面
- 对接后填写以下信息：
  - 字印字段（印在珠宝上的文字）
  - 材质字段（可编辑）
  - 手寸/链长字段
  - 设计师选择与绑定

#### 4.2.3 订单状态管理
**状态流转：**
1. 待设计师设计
2. 设计中
3. 待建模师设计
4. 建模中
5. 待工艺验证
6. 待生产
7. 生产中
8. 已完成
9. 已取消

**特殊状态处理：**
- 售中客服可在任何环节设置订单为"已取消"
- "已取消"状态订单不可再次操作
- 状态变更记录与审计

### 4.3 设计任务管理模块

#### 4.3.1 设计师工作台
**待设计栏目：**
- 显示分配给自己的订单列表
- 查看订单详细信息
- 开始设计操作

**设计信息录入：**
1. **工艺信息管理**
   - 勾选常见工艺：珐琅、拉丝、喷砂、钉砂等（管理员可配置）
   - 手动添加工艺选项
   - 为每个工艺添加额外工费

2. **石料信息管理**
   - 支持多个石料录入
   - 每个石料包含字段：
     - 石料类型
     - 形状
     - 尺寸
     - 数量
     - 价格
     - 备注

3. **设计图管理**
   - 上传多张设计图
   - 支持替换/删除/重新上传
   - 图片预览与版本管理

**设计完成：**
- 点击"设计通过客户检验"
- 订单转移到设计师"已完成"栏目
- 自动进入售中客服"待建模师设计"栏目

### 4.4 建模任务管理模块

#### 4.4.1 建模师工作台
**待建模栏目：**
- 显示分配给自己的订单列表
- 查看设计信息和客户需求
- 开始建模操作

**建模信息录入：**
1. **订单克重上传**
   - 录入精确克重信息
   - 支持修改和重新上传

2. **建模文件管理**
   - 上传3D建模文件
   - 支持替换/删除/重新上传
   - 文件格式支持与预览

**建模完成：**
- 点击"建模通过客户检验"
- 订单转移到建模师"待工艺评审"栏目
- 自动进入售中客服"待工艺验证"栏目

### 4.5 工艺评审与报价模块

#### 4.5.1 跟单员工作台
**待工艺评审栏目：**
- 查看需要评审的订单
- 审核工艺和建模文件
- 删除不合理工艺并反馈驳回原因

**评审操作：**
- 点击"已评审通过"：进入报价阶段
- 点击"已评审驳回"：需要售中经理处理

#### 4.5.2 报价管理（售中客服）
**报价信息完善：**
1. **信息检查与修正**
   - 工艺信息核对
   - 石料信息核对
   - 克重信息核对

2. **工费信息添加**
   - 基础工费计算
   - 额外工艺工费汇总

3. **增值服务选项**
   - 是否设计买断 + 申请版权证书
     - 系统默认加价固定值（管理员可调整）
   - 是否申请鉴定证书
     - 系统默认加价固定值（管理员可调整）
   - 是否保密不宣传
   - 其他备注信息

4. **材质单价自动计算**
   - 系统自动获取转入"待生产"当日金/银大盘价
   - 计算公式：
     - 银价 = 大盘价 + 3.5%
     - 金价 = 大盘价 + 10元
   - 管理员可修改系统配置
   - 售中客服可手动修改计算结果

**报价完成：**
- 标记订单为"待生产"
- 生成完整报价单

### 5.2 部署架构

#### 5.2.1 后端Docker容器化
- **Docker镜像**：基于OpenJDK的Spring Boot应用镜像，包含数据库迁移工具
- **Dockerfile配置**：
  ```dockerfile
  # 使用多阶段构建减少镜像大小
  FROM openjdk:17-jdk-slim as builder
  WORKDIR /app
  COPY mvnw .
  COPY .mvn .mvn
  COPY pom.xml .
  RUN ./mvnw dependency:go-offline
  
  COPY src src
  RUN ./mvnw package -DskipTests
  
  # 运行时镜像
  FROM openjdk:17-jdk-slim
  WORKDIR /app
  
  # 安装Flyway数据库迁移工具
  RUN apt-get update && apt-get install -y wget unzip && \
      wget -q -O flyway.tar.gz https://repo1.maven.org/maven2/org/flywaydb/flyway-commandline/9.22.0/flyway-commandline-9.22.0-linux-x64.tar.gz && \
      tar -xzf flyway.tar.gz && \
      mv flyway-9.22.0 /opt/flyway && \
      rm flyway.tar.gz && \
      apt-get remove -y wget unzip && apt-get autoremove -y && rm -rf /var/lib/apt/lists/*
  
  ENV PATH="/opt/flyway:${PATH}"
  
  COPY --from=builder /app/target/*.jar app.jar
  COPY src/main/resources/db/migration /app/db/migration
  
  EXPOSE 8851
  
  # 启动脚本：先执行数据库迁移，再启动应用
  COPY docker-entrypoint.sh /app/
  RUN chmod +x /app/docker-entrypoint.sh
  
  ENTRYPOINT ["/app/docker-entrypoint.sh"]
  ```
  
- **启动脚本 (docker-entrypoint.sh)**：
  ```bash
  #!/bin/bash
  set -e
  
  # 等待数据库就绪
  echo "等待MySQL数据库就绪..."
  while ! nc -z mysql 3306; do
    sleep 1
  done
  
  # 执行数据库迁移
  echo "执行数据库迁移..."
  flyway -url=jdbc:mysql://mysql:3306/jewelry_system \
         -user=$DB_USER \
         -password=$DB_PASSWORD \
         -locations=filesystem:/app/db/migration \
         migrate
  
  # 启动Spring Boot应用
  echo "启动应用..."
  exec java -jar app.jar
  ```
  
- **容器配置**：
  - 内存限制：2GB
  - CPU限制：2核心
  - 健康检查端点：/actuator/health
  - 环境变量：DB_USER, DB_PASSWORD（从Docker secrets或环境变量获取）

### 5.3 CI/CD流水线设计

#### 5.3.1 GitHub Actions工作流
```yaml
name: Build and Deploy
on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    
    - name: Set up JDK 17
      uses: actions/setup-java@v2
      with:
        java-version: '17'
        distribution: 'temurin'
    
    - name: Build with Maven
      run: mvn clean package -DskipTests
    
    - name: Run tests
      run: mvn test
    
    - name: Build Docker image
      run: docker build -t jewelry-system-backend:latest .
    
    - name: Database migration check
      run: |
        # 检查数据库迁移脚本
        # 自动执行Flyway/Liquibase迁移
        
    - name: Deploy to server
      uses: appleboy/ssh-action@master
      with:
        host: 39.102.213.51
        username: ${{ secrets.SSH_USERNAME }}
        key: ${{ secrets.SSH_PRIVATE_KEY }}
        script: |
          docker stop jewelry-backend || true
          docker rm jewelry-backend || true
          docker pull jewelry-system-backend:latest
          docker run -d \
            --name jewelry-backend \
            -p 8851:8851 \
            -v /data/jewelry/files:/app/files \
            -v /data/jewelry/logs:/app/logs \
            --restart always \
            jewelry-system-backend:latest
```

#### 5.3.2 数据库迁移自动化
