# 定制选项白板

来源：`whiteboard_exported_image.pdf`（一页思维导图）。图上是若干棵并列的选项树，没有总标题。右下有一张戒指参考图（蓝珐琅、金色尖角、一颗绿色长方形主石），图上没有文字说明。

戒圈测量方法（挂在「戒指 / 圈号」旁）：使用一根细线将手指最粗处缠绕一圈，不要缠绕太紧或太松，展开后测量周长，与尺码表核对选择合适的圈号。
