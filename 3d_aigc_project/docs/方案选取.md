## 方案1：条件生成+后处理融合方案

### 1.1 方案概述

**核心思路**：利用Hunyuan3D-Omni的点云/体素条件控制能力，将镶嵌底座作为几何约束输入，引导模型生成与底座对齐的珠宝主体，最后通过后处理融合为完整模型。

### 1.2 适用条件

| 条件类型 | 具体要求 |
|---------|---------|
| **数据条件** | 已有镶嵌底座3D模型（OBJ/GLB/STEP格式） |
| **硬件条件** | GPU 12GB+（推荐RTX 4080/4090） |
| **软件条件** | Python 3.9+, CUDA 11.8+, PyTorch 2.0+ |
| **人员条件** | 熟悉3D数据处理（点云、网格操作） |
| **时间预算** | 1-2个月搭建完整管线 |

```python
# modules/pointcloud_conditioner.py
import open3d as o3d
import numpy as np
from typing import Tuple

class PointCloudConditioner:
    """将镶嵌底座Mesh转换为点云条件"""
    
    def __init__(self, num_points: int = 2048, include_normals: bool = True):
        self.num_points = num_points
        self.include_normals = include_normals
    
    def mesh_to_pointcloud(self, mesh_path: str) -> np.ndarray:
        """
        将Mesh转换为点云表示
        
        Args:
            mesh_path: 镶嵌底座模型路径
            
        Returns:
            points: [N, 3] 点坐标
            normals: [N, 3] 法向量 (可选)
        """
        # 加载Mesh
        mesh = o3d.io.read_triangle_mesh(mesh_path)
        mesh.compute_vertex_normals()
        
        # 均匀采样点云
        pcd = mesh.sample_points_uniformly(number_of_points=self.num_points)
        
        # 提取点和法向量
        points = np.asarray(pcd.points)
        
        if self.include_normals:
            # 计算法向量
            pcd.estimate_normals()
            pcd.orient_normals_consistent_tangent_plane(100)
            normals = np.asarray(pcd.normals)
            return points, normals
        
        return points
    
    def add_contact_region_markers(self, points: np.ndarray, 
                                   contact_regions: list) -> np.ndarray:
        """
        标记接触区域（宝石与底座的接触点）
        用于引导AI在正确位置生成宝石
        """
        # 为接触区域点添加额外特征维度
        features = np.zeros((len(points), 1))
        
        for region in contact_regions:
            # region: (center, radius) 定义接触区域
            distances = np.linalg.norm(points - region['center'], axis=1)
            mask = distances < region['radius']
            features[mask] = 1.0  # 标记为接触区域
        
        return np.concatenate([points, features], axis=1)
```

```python
# modules/conditional_generator.py
from hy3dgen.shapegen import HunyuanDiTPipeline
from hy3dgen.texgen import HunyuanPaintPipeline
import torch

class JewelryConditionalGenerator:
    """基于Hunyuan3D-Omni的条件生成器"""
    
    def __init__(self, device='cuda'):
        self.device = device
        
        # 加载Hunyuan3D-Omni模型
        self.shape_pipeline = HunyuanDiTPipeline.from_pretrained(
            'tencent/Hunyuan3D-2',
            variant='omni',
            torch_dtype=torch.float16
        ).to(device)
        
        self.tex_pipeline = HunyuanPaintPipeline.from_pretrained(
            'tencent/Hunyuan3D-2',
            torch_dtype=torch.float16
        ).to(device)
    
    def generate(self, 
                 image_path: str,
                 point_cloud: np.ndarray,
                 text_prompt: str = None,
                 bbox_condition: Tuple[float, float, float] = None) -> dict:
        """
        条件生成珠宝主体
        
        Args:
            image_path: 设计图路径
            point_cloud: 底座点云 [N, 3] 或 [N, 6] (含法向量)
            text_prompt: 文本描述（可选）
            bbox_condition: 生成区域边界框 (width, height, depth)
            
        Returns:
            result: 包含mesh和texture的字典
        """
        # 构建条件输入
        conditions = {
            'point_cloud': point_cloud,
            'image': image_path,
        }
        
        if text_prompt:
            conditions['text'] = text_prompt
        
        if bbox_condition:
            conditions['bbox'] = bbox_condition
        
        # 生成形状 (SDF/点云表示)
        shape_output = self.shape_pipeline(
            **conditions,
            num_inference_steps=50,
            guidance_scale=7.5
        )
        
        # 生成纹理
        textured_mesh = self.tex_pipeline(
            mesh=shape_output['mesh'],
            image=image_path
        )
        
        return {
            'mesh': textured_mesh,
            'sdf': shape_output.get('sdf'),
            'point_cloud_gen': shape_output.get('point_cloud')
        }
```

**模块3: 网格融合器**

```python
# modules/mesh_fusion.py
import open3d as o3d
import trimesh
import numpy as np
from scipy.spatial import cKDTree

class JewelryMeshFusion:
    """将AI生成的珠宝主体与镶嵌底座融合"""
    
    def __init__(self, fusion_method='sdf_boolean'):
        self.fusion_method = fusion_method
    
    def align_and_fuse(self,
                       base_mesh_path: str,
                       generated_mesh: trimesh.Trimesh,
                       contact_threshold: float = 0.5) -> trimesh.Trimesh:
        """
        对齐并融合两个Mesh
        
        Args:
            base_mesh_path: 镶嵌底座路径
            generated_mesh: AI生成的珠宝主体
            contact_threshold: 接触检测阈值(mm)
            
        Returns:
            fused_mesh: 融合后的完整珠宝模型
        """
        # 1. 加载底座
        base_mesh = trimesh.load(base_mesh_path)
        
        # 2. ICP对齐
        aligned_gen = self._icp_align(base_mesh, generated_mesh)
        
        # 3. 根据融合方法选择策略
        if self.fusion_method == 'sdf_boolean':
            return self._sdf_boolean_fusion(base_mesh, aligned_gen)
        elif self.fusion_method == 'poisson':
            return self._poisson_fusion(base_mesh, aligned_gen)
        else:
            return self._naive_union(base_mesh, aligned_gen)
    
    def _icp_align(self, target: trimesh.Trimesh, 
                   source: trimesh.Trimesh) -> trimesh.Trimesh:
        """使用ICP进行精确对齐"""
        # 转换为Open3D格式
        target_pcd = self._trimesh_to_o3d(target).sample_points_uniformly(10000)
        source_pcd = self._trimesh_to_o3d(source).sample_points_uniformly(10000)
        
        # 执行ICP
        result = o3d.pipelines.registration.registration_icp(
            source_pcd, target_pcd, 0.02, np.eye(4),
            o3d.pipelines.registration.TransformationEstimationPointToPoint()
        )
        
        # 应用变换
        source.apply_transform(result.transformation)
        return source
    
    def _sdf_boolean_fusion(self, mesh_a: trimesh.Trimesh, 
                           mesh_b: trimesh.Trimesh) -> trimesh.Trimesh:
        """基于SDF的布尔融合（推荐）"""
        # 将两个Mesh转换为SDF场
        # 使用并集操作: SDF_union = min(SDF_a, SDF_b)
        # 然后用Marching Cubes提取等值面
        
        # 这里使用OpenVDB或自定义实现
        # 伪代码：
        sdf_a = self._mesh_to_sdf(mesh_a)
        sdf_b = self._mesh_to_sdf(mesh_b)
        sdf_union = np.minimum(sdf_a, sdf_b)
        
        return self._sdf_to_mesh(sdf_union)
    
    def _post_process(self, mesh: trimesh.Trimesh) -> trimesh.Trimesh:
        """后处理：拓扑修复、平滑"""
        # 确保流形
        mesh = mesh.fill_holes()
        mesh = mesh.remove_duplicate_faces()
        mesh = mesh.remove_degenerate_faces()
        
        # Laplacian平滑（仅在非特征区域）
        # 保留镶嵌结构的锐利边缘
        
        return mesh
```

### 1.5 优势与局限

| 优势 | 局限 |
|------|------|
| 快速落地，1-2个月可出原型 | 底座与生成的接缝处可能需要人工调整 |
| 利用成熟的Hunyuan3D-Omni，生成质量高 | 对复杂镶嵌结构的对齐精度依赖ICP |
| 点云条件提供几何约束，可控性强 | 需要处理SDF到Mesh的精度损失 |
| 开源方案，无授权费用 | 生成速度受扩散模型限制（~30秒/模型） |

### 1.6 关键技术指标

| 指标 | 目标值 | 验证方法 |
|------|--------|---------|
| 底座保留精度 | < 0.05mm 误差 | 与原始模型Hausdorff距离 |
| 接缝平滑度 | 无明显阶梯/缝隙 | 视觉检查+曲率连续性分析 |
| 生成成功率 | > 85% | 批量测试统计 |
| 单模型生成时间 | < 60秒 | 计时测试 |

```python
# data/prepare_dataset.py
import trimesh
import numpy as np
from pathlib import Path
import json

class JewelryDatasetBuilder:
    """构建珠宝训练数据集"""
    
    def __init__(self, output_dir: str):
        self.output_dir = Path(output_dir)
        self.output_dir.mkdir(parents=True, exist_ok=True)
    
    def process_model(self, model_path: str, category: str):
        """处理单个模型"""
        mesh = trimesh.load(model_path)
        
        # 1. 标准化尺寸 (以戒指为例，内径约16-20mm)
        mesh = self._normalize_scale(mesh, target_size=20.0)
```

```python
# training/finetune_hunyuan3d.py
import torch
from peft import LoraConfig, get_peft_model
from hy3dgen.shapegen import HunyuanDiTPipeline
from torch.utils.data import DataLoader

class JewelryTrainer:
    """珠宝3D模型微调训练器"""
    
    def __init__(self, config_path: str):
        self.config = load_config(config_path)
        self.setup_model()
        self.setup_data()
    
    def setup_model(self):
        """加载并配置模型"""
        # 加载基础模型
        self.pipeline = HunyuanDiTPipeline.from_pretrained(
            self.config.model.base_model,
            torch_dtype=torch.float16
        )
        
        # 配置LoRA
        lora_config = LoraConfig(
            r=self.config.model.lora.r,
            lora_alpha=self.config.model.lora.alpha,
            target_modules=self.config.model.lora.target_modules,
            lora_dropout=0.1,
        )
        
        # 应用LoRA
        self.pipeline.transformer = get_peft_model(
            self.pipeline.transformer, 
            lora_config
        )
        
        # 条件编码器
        self.condition_encoder = PointNet2Encoder(
            in_channels=self.config.model.condition_encoder.in_channels,
            out_channels=self.config.model.condition_encoder.out_channels
        )
    
    def train(self):
        """训练循环"""
        for epoch in range(self.config.training.num_epochs):
            for batch in self.train_dataloader:
                # 前向传播
                images = batch['images']  # [B, V, C, H, W]
                point_clouds = batch['point_clouds']  # [B, N, 6]
                captions = batch['captions']
                
                # 编码条件
                condition_features = self.condition_encoder(point_clouds)
                
                # DiT前向
                loss = self.pipeline(
                    images=images,
                    text=captions,
                    condition=condition_features
                )
                
                # 反向传播
                loss.backward()
                
                if self.step % self.config.training.gradient_accumulation_steps == 0:
                    self.optimizer.step()
                    self.optimizer.zero_grad()
                
                # 保存检查点
                if self.step % self.config.training.save_steps == 0:
                    self.save_checkpoint()
```

## 融合方案：双轨增强融合方案

### 3.1 方案概述

**核心思路**：融合方案1的快速部署能力和方案2的长期优化潜力，构建一个**双轨并行**的系统架构：
- **轨道A（生产轨道）**：基于方案1的条件生成+后处理，快速满足生产需求
- **轨道B（优化轨道）**：持续收集生产数据，微调专用模型，逐步替换/增强轨道A
- **融合层**：智能路由和质量评估，确保系统稳定性和输出质量

### 3.2 适用条件

| 条件类型 | 具体要求 |
|---------|---------|
| **数据条件** | 初期：50-100个示例模型；持续收集生产数据 |
| **硬件条件** | 生产服务器：12GB GPU；训练服务器：24GB+ GPU |
| **软件条件** | 方案1 + 方案2的全部依赖 |
| **人员条件** | 3D工程师（生产）+ 算法工程师（训练） |
| **时间预算** | 第1个月上线方案1；第3-6个月融合方案2 |

#### Phase 4: 智能路由与融合 (第4-6个月)

**目标**：实现智能路由和双轨结果融合

```python
# fusion/smart_router.py
class SmartRouter:
    """智能路由: 决定使用哪个轨道，或融合两者"""
    
    def __init__(self, track_a: TrackAProducer, track_b: TrackBProducer):
        self.track_a = track_a
        self.track_b = track_b
        self.quality_assessor = QualityAssessor()
    
    def route(self, request: dict) -> dict:
        """智能路由决策"""
        # 1. 评估输入特征
        complexity = self._assess_complexity(request)
        urgency = request.get('urgency', 'normal')
        
        # 2. 决策逻辑
        if urgency == 'high' or not self.track_b.is_ready():
            # 紧急需求或轨道B未就绪 → 使用轨道A
            return self._produce_with_a(request)
        
        elif complexity == 'high':
            # 复杂设计 → 双轨并行，选择最佳
            return self._produce_hybrid(request)
        
        else:
            # 常规设计 → 优先使用轨道B
            return self._produce_with_b(request)
    
    def _produce_hybrid(self, request: dict) -> dict:
        """双轨并行，融合结果"""
        # 并行生成
        result_a = self.track_a.produce(**request)
        result_b = self.track_b.produce(**request)
        
        # 质量评估
        score_a = self.quality_assessor.assess(result_a)
        score_b = self.quality_assessor.assess(result_b)
        
        # 融合策略
        if abs(score_a - score_b) < 10:
            # 质量相近 → 几何融合
            fused = self._geometric_fusion(result_a, result_b)
            return fused
        else:
            # 质量差异大 → 选择高分
            return result_a if score_a > score_b else result_b
    
    def _geometric_fusion(self, result_a: dict, result_b: dict) -> dict:
        """几何层面融合两个结果"""
        # 基于SDF的加权融合
        # 在重叠区域取平均，在非重叠区域取并集
        
        sdf_a = self.mesh_to_sdf(result_a['mesh'])
        sdf_b = self.mesh_to_sdf(result_b['mesh'])
        
        # 加权融合 (可根据置信度调整权重)
        weight_a = result_a.get('confidence', 0.5)
        weight_b = result_b.get('confidence', 0.5)
        
        sdf_fused = (sdf_a * weight_a + sdf_b * weight_b) / (weight_a + weight_b)
        
        mesh_fused = self.sdf_to_mesh(sdf_fused)
        
        return {
            'mesh': mesh_fused,
            'source': 'hybrid',
            'components': ['track_a', 'track_b']
        }
```

### 3.5 优势分析

| 维度 | 融合方案优势 |
|------|-------------|
| **稳定性** | 双轨冗余，单点故障不影响生产；轨道A始终可用作为保底 |
| **准确性** | 轨道B持续优化，质量逐步提升；智能路由选择最优结果 |
| **可扩展性** | 数据飞轮持续积累，模型自动迭代；可扩展更多轨道（如方案B的参数化轨道） |
| **风险控制** | 质量评估层拦截低质量输出；人工反馈闭环 |
| **投资回报** | 第1个月即有产出；长期收益随数据积累递增 |

### 4.2 选型建议

#### 推荐选择：融合方案

**理由**：
1. **风险可控**：轨道A快速上线，确保业务不等待
2. **持续优化**：数据飞轮驱动轨道B持续改进
3. **灵活演进**：可根据业务需求调整双轨权重
4. **技术储备**：积累的数据和模型可作为未来AI能力的基础

#### 实施路线图

```
Month 1:  轨道A部署 → 生产就绪，开始收集数据
Month 2:  数据飞轮 → 建立数据管道，开始标注
Month 3:  轨道B训练 → 启动微调训练，A/B测试
Month 4:  双轨并行 → 智能路由上线，逐步增加轨道B流量
Month 5:  优化迭代 → 基于反馈优化模型和路由策略
Month 6+: 持续演进 → 轨道B成为主轨道，探索新能力
```

### 4.3 决策树

```
是否需要立即投产？
├── 是 → 先实施方案1，同时准备融合方案
└── 否 → 是否有足够数据和算力？
    ├── 是 → 直接实施方案2，长期效果最优
    └── 否 → 融合方案，分阶段建设
```
