# 模型下载指南

由于当前网络环境限制，无法直接从HuggingFace下载模型。请使用以下任一方式获取模型：

---

## 方式1：使用代理下载（推荐）

如果您有代理，请设置后重试：

```bash
# 设置代理
set HTTP_PROXY=http://your-proxy:port
set HTTPS_PROXY=http://your-proxy:port

# 下载模型
cd 3d_aigc_project
git lfs install
git clone https://huggingface.co/tencent/Hunyuan3D-2mini models/hunyuan3d-2mini
```

---

## 方式2：使用VPN下载

1. 开启VPN连接
2. 访问：https://huggingface.co/tencent/Hunyuan3D-2mini
3. 点击 "Files and versions" 标签
4. 下载以下目录中的所有文件：
   - `hunyuan3d-dit-v2-mini/` (形状生成模型，约1.2GB)
   - `hunyuan3d-paint-v2-mini/` (纹理生成模型，约1.5GB)

---

## 方式3：使用网盘下载（如果有）

如果有人分享到百度网盘/阿里云盘等，可以直接下载后放到：

```
3d_aigc_project/models/hunyuan3d-2mini/
├── hunyuan3d-dit-v2-mini/
│   ├── config.yaml
│   └── model.fp16.safetensors (或 model.fp16.ckpt)
└── hunyuan3d-paint-v2-mini/
    ├── config.yaml
    └── model.fp16.safetensors (或 model.fp16.ckpt)
```

---

## 方式4：使用腾讯云API（无需下载模型）

如果模型下载困难，可以直接使用腾讯云混元3D API：

1. 注册腾讯云账号：https://cloud.tencent.com
2. 开通混元3D服务
3. 获取API密钥
4. 在 `.env` 文件中配置：
   ```
   USE_TENCENT_API=true
   TENCENT_SECRET_ID=your_secret_id
   TENCENT_SECRET_KEY=your_secret_key
   ```

使用API的优点：
- 无需下载大模型文件
- 无需本地GPU
- 生成速度更快
- 质量更稳定

---

## 验证模型是否正确放置

下载完成后，运行以下命令验证：

```bash
cd 3d_aigc_project
python scripts/download-models.py --verify-only
```

## 模型文件清单

| 文件 | 大小 | 用途 |
|------|------|------|
| hunyuan3d-dit-v2-mini/config.yaml | ~1KB | 模型配置 |
| hunyuan3d-dit-v2-mini/model.fp16.safetensors | ~1.2GB | 形状生成权重 |
| hunyuan3d-paint-v2-mini/config.yaml | ~1KB | 纹理模型配置 |
| hunyuan3d-paint-v2-mini/model.fp16.safetensors | ~1.5GB | 纹理生成权重 |

**总大小：约2.7GB**
